01 — About

작은 것부터,
하나씩 만듭니다.

한 줄의 코드, 하나의 센서, 하나의 프롬프트, 하나의 픽셀. FineDust Works는 작은 부분부터 직접 만들고 시험하며 프로젝트를 구체화합니다.

하드웨어와 소프트웨어, 개발 도구와 게임을 두루 다룹니다. 한 사람이 설계부터 구현까지 맡아, 필요한 부분을 빠르게 시도하고 개선합니다.

02 — Domains

만들고 있는 여섯 가지 분야

  1. /01

    Robotics

    소형 로봇을 만듭니다. 액추에이터, 센서 퓨전, 제어 루프까지 직접 설계합니다.

    • ROS 2
    • Embedded
    • Control
  2. /02

    Tiny Objects

    손바닥 위의 하드웨어. 임베디드 시스템부터 소형 기구와 일상용 비전원 액세서리까지 직접 설계하고 제작합니다.

    • ESP32
    • PCB
    • Firmware
  3. /03

    Tools

    반복 작업을 줄이는 도구. CLI, 에디터 확장, 워크플로 자동화, 개발자 경험.

    • CLI
    • Plugins
    • DX
  4. /04

    AI Agents

    스스로 판단하고 도구를 쓰는 에이전트. LLM 오케스트레이션, MCP, 자동화 파이프라인.

    • LLM
    • MCP
    • Agents
  5. /05

    Software

    웹과 데스크톱, 모바일 앱. 작고 빠르며 오래 쓰기 좋은 제품을 만듭니다.

    • Web
    • Desktop
    • Mobile
  6. /06

    Games

    직접 플레이하며 다듬는 인디 게임. 프로토타입과 인터랙티브 아트도 만듭니다.

    • Unity
    • Godot
    • Shaders

03 — Approach

아이디어를 구현하는 과정

Disperse

관찰하고 나눠보기

문제를 작은 단위로 나누고, 무엇이 필요한지 살펴봅니다.

Gather

모으고 시험하기

스케치, 코드, 납땜 등으로 프로토타입을 만들고 아이디어를 시험합니다.

Condense

정리하고 다듬기

필요한 기능을 중심으로 정리하고, 안정적으로 동작하도록 다듬습니다.

Release

공개하고 개선하기

결과물을 공개하고, 사용하면서 얻은 피드백을 반영합니다.
