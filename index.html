01 — About

미세먼지처럼 작게,
그러나 어디에나.

큰 시스템도 결국 작은 입자들의 집합입니다. 한 줄의 코드, 하나의 센서, 하나의 프롬프트, 하나의 픽셀. FineDust Works는 그 작은 단위를 정성껏 다루는 것에서 시작합니다.

하드웨어와 소프트웨어, 도구와 놀이의 경계를 나누지 않습니다. 한 사람이 처음부터 끝까지 설계하기 때문에 결과물은 가볍고, 일관되고, 빠르게 움직입니다.

02 — Domains

입자가 모이는 여섯 개의 영역

  1. /01

    Robotics

    작고 영리한 로봇. 액추에이터, 센서 퓨전, 제어 루프까지 직접 설계합니다.

    • ROS 2
    • Embedded
    • Control
  2. /02

    Tiny Devices

    손바닥 위의 하드웨어. MCU 펌웨어, PCB, 인클로저, 저전력 IoT.

    • ESP32
    • PCB
    • Firmware
  3. /03

    Tools

    반복을 없애는 도구. CLI, 에디터 확장, 워크플로 자동화, 개발자 경험.

    • CLI
    • Plugins
    • DX
  4. /04

    AI Agents

    스스로 판단하고 도구를 쓰는 에이전트. LLM 오케스트레이션, MCP, 자동화 파이프라인.

    • LLM
    • MCP
    • Agents
  5. /05

    Software

    웹과 데스크톱, 모바일 앱. 작고 빠르며 오래 쓰기 좋은 제품을 만듭니다.

    • Web
    • Desktop
    • Mobile
  6. /06

    Games

    입자처럼 흩어지고 모이는 경험. 인디 게임, 프로토타입, 인터랙티브 아트.

    • Unity
    • Godot
    • Shaders

03 — Approach

흩어진 것에서 형태로

Disperse

관찰하고 흩어보기

문제를 가장 작은 단위로 분해합니다. 무엇이 진짜 필요한지 찾을 때까지.

Gather

모으고 시험하기

빠른 프로토타입으로 입자를 모읍니다. 납땜이든, 코드든, 스케치든.

Condense

응집하고 다듬기

남길 것만 남기고 단단하게 만듭니다. 군더더기 없는 결과물로.

Release

내보내고 퍼뜨리기

세상에 공개하고, 피드백을 다시 작은 입자로 받아들여 반복합니다.
